🛡️ VAPT Automation Framework
Overview

The VAPT Automation Framework is a Python-based cybersecurity tool that automates key phases of Vulnerability Assessment and Penetration Testing (VAPT).

It performs:

Network Port Scanning (Multithreaded)
Vulnerability Detection
Risk Scoring
Log Analysis
Threat Detection
Automated Report Generation (CSV & JSON)
Email Alert System

This project simulates a real-world security assessment pipeline used in cybersecurity environments.

 Features
- Core Features
- Multithreaded Port Scanner
- Service-based Vulnerability Detection
- Risk Scoring Engine (LOW / MEDIUM / HIGH)
- Automated Report Generation (CSV + JSON)
- Email Alert System (SMTP)
- Advanced Features
-Threat Detection Module
📁 Log Analysis System
⚙️ Modular Architecture (Production-style design)
🧩 Config-driven system
